    Part 5: Edge Split

    Implementation Detail

    I implemented the edge split operation by tracking and reassigning pointers for all affected mesh elements. To manage the complexity, I first drew diagrams of the mesh before and after the split to label every vertex, edge, face, and half-edge.

    Non-Boundary Edge Split

    1. Like Part 4, I first iterate through the mesh starting from e0's half-edge and use the next pointers to collect every single element in the two triangles.
    2. In summary, the split operation creates \(1\) new vertex \(m\), \(3\) new edges, \(2\) new faces, and \(6\) new half-edges. The position of the new vertex \(m\) is set to the midpoint of the original edge: \(m = \frac{b + c}{2}\)
    3. After creating the new elements, I established four triangle loops by reassigning pointers:
      • Face \(f_0\): triangle \((b, m, a)\). Its half-edge loop is: \(h_0(b \rightarrow m) \rightarrow h_9(m \rightarrow a) \rightarrow h_2(a \rightarrow b)\).
      • Face \(f_1\): triangle \((m,b,d)\). Its half-edge loop is: \(h_3(m \rightarrow b) \rightarrow h_4(b \rightarrow d) \rightarrow h_{10}(d \rightarrow m)\)
      • Face \(f_2\): triangle \((m,c,a)\). Its half-edge loop is: \(h_6(m \rightarrow c) \rightarrow h_1(c \rightarrow a) \rightarrow h_8(a \rightarrow m)\)
      • Face \(f_3\): triangle \((c,m,d)\). Its half-edge loop is: \(h_7(c \rightarrow m) \rightarrow h_{11}(m \rightarrow d) \rightarrow h_5(d \rightarrow c)\)
    4. Finally, I updated the pointers for all \(5\) vertices, \(8\) edges, and \(4\) faces to ensure they pointed to a valid halfedge.

    Extra Credit: Boundary Edge Split

    I also implemented support for splitting boundary edges. If an edge is on a boundary, only the non-boundary face is split into two triangles. The virtual boundary face is not split; instead, the new vertex \(m\) is simply inserted into the existing boundary loop.

    Because we only split one triangle, this operation requires fewer new elements: \(1\) new vertex, \(1\) new face, \(2\) new edges, and \(4\) new half-edges.

    The implementation is nearly identical to the non-boundary edge split, with a few key differences:

    • Finding the Boundary Predecessor: To insert the new vertex into the boundary loop, I needed the predecessor half-edge (h3_prev). Since halfedges do not have a prev pointer, I iterated around vertex \(c\) using h_it->twin()->next() until I found the halfedge whose twin is on the boundary.
    • New half-edge loops:
      • Face \(f_0\): triangle \((b, m, a)\). Its half-edge loop is: \(h_0(b \rightarrow m) \rightarrow h_9(m \rightarrow a) \rightarrow h_2(a \rightarrow b)\).
      • Face \(f_1\): triangle \((m,c,a)\). Its half-edge loop is: \(h_6(m \rightarrow c) \rightarrow h_1(c \rightarrow a) \rightarrow h_8(a \rightarrow m)\)
      • Boundary: \(h_{3-prev}(x→c) → h7(c→m) → h3(m→b) → h_{3-next}(b→y)\)

    Implementation Tricks

    My debugging journey was relatively smooth—I only encountered some basic errors, like typos.. I avoided major bugs by treating this part similarly to Part 4. Before writing any code, I drew the "before" and "after" states of the triangles on scratch paper. I labeled every variable and mapped out the exact pointer relationships. Translating this physical diagram directly into code ensured that I did not lose track of any pointers.

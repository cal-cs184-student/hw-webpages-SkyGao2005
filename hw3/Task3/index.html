    Part 3: Direct Illumination

    Direct Lighting Implementations

    Uniform Hemisphere Sampling

    In PathTracer::estimate_direct_lighting_hemisphere, we use Monte Carlo integration to estimate the direct lighting by sampling uniformly over a hemisphere.

    We loop num_samples times. In each iteration, we sample a random incoming direction \(w_{in}\) using hemisphereSampler->get_sample(). We convert this local direction to world space and create a sample ray starting from the hit point hit_p.

    Then, We check if this ray intersects any object in the scene using the BVH. If it hits a light source, we get its emitted radiance. We calculate the light contribution using the reflection equation: \(f(w_{out}, w_{in}) \cdot L_i \cdot \cos(\theta) \cdot 2\pi\). The \(2\pi\) term comes from dividing by the probability density function of uniform hemisphere sampling, which is \(1 / 2\pi\).

    Finally, we sum these values and divide by num_samples to get the average.

    Importance Sampling

    In PathTracer::estimate_direct_lighting_importance, instead of sampling random directions, we directly sample the light sources.

    We iterate through every light in scene->lights. For each light, we take ns_area_light samples (or just 1 sample if it is a point light). Then, we use light->sample_L to get the incoming radiance \(L_i\), the world direction to the light \(w_{i\_world}\), the distance to the light, and the \(\text{pdf}\).

    We convert the direction to local space and check if the light is behind the surface (\(w_{i\_local}.z \le 0\)). If it is in front, we cast a shadow ray from hit_p towards the light. The max_t of the shadow ray is set to distToLight - EPS_F to avoid intersecting the light itself. If the shadow ray does not intersect anything in the BVH, the point is not in shadow. We then calculate the contribution using the formula: \(f(w_{out}, w_{i\_local}) \cdot L_i \cdot \frac{\cos(\theta)} {\text{pdf}}\).

    Finally, we average the samples for each light and add them together to get the total direct lighting.

    Comparison

    Uniform hemisphere sampling shoots rays in random directions, meaning many rays will simply hit empty space or non-emitting objects instead of a light source. This wastes a lot of computational power and results in a highly noisy image. In contrast, lighting sampling directly targets the light sources, guaranteeing that every sampled direction points toward a light. The only reason a sample would not contribute to the lighting is if it is blocked by an object. Because of this targeted approach, importance sampling converges much faster and produces significantly less noise with the same number of samples.

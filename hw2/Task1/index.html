    Part 1: Bezier Curves with 1D de Casteljau Subdivision

    de Casteljau's Algorithm

    Instead of calculating the complex polynomial equation directly, de Casteljau's Algorithm uses repeated linear interpolation to find a specific point on the curve for a given parameter \(t\), where \(t \in [0, 1]\).

    We start with \(n\) initial control points: \(P_0, P_1, P_2, \dots, P_{n-1}\). For every two adjacent control points \(P_i\) and \(P_{i+1}\), we find a new point \(P'_i\) between them using the parameter \(t\). The mathematical formula for this is: \(P'_i = (1 - t)P_i + tP_{i+1}\)

    After one full step of interpolation, we get a new set of \(n-1\) points. We repeat this exact same process on the new set of points.

    Eventually, we stop the recursion when we are left with exactly one single point. This final point is guaranteed to lie on the Bezier curve at the specified parameter \(t\).

    Implementation Details

    First, I implemented the helper function lerp(). The function simply takes two Vector2D points and the double t, and returns the newly interpolated Vector2D point \((1 - t)P_0 + tP_1\).

    Next, I implemented the evaluateStep() function. This function is responsible for calculating one single recursive step of the algorithm.

    • It takes a std::vector<Vector2D> containing the current level's points, and returns a std::vector<Vector2D> to store the intermediate points.
    • I iterate through the given points, call lerp(points[i], points[i + 1], t) to interpolate between the current point and the next point, using the class member variable t. The resulting point is pushed into the result vector.
    • Finally, the function returns the result vector, which now contains one less point than the input vector, completing next level of subdivision.

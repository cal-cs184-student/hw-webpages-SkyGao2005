    Part 2: Bezier Surfaces with Separable 1D de Casteljau

    Extension of de Casteljau's Algorithm to Bezier Surfaces

    We can solve the surface evaluation by separating it into multiple 1D operations. The inputs to this algorithm are an \(n \times n\) grid of original control points, denoted as \(P_{i,j}\), and two scalar parameters, \(u\) and \(v\).

    1. Row Evaluation (using parameter \(u\)): We first consider that each row of \(n\) control points, \(P_{i,0}, P_{i,1}, \dots, P_{i,n-1}\), defines a 1D Bezier curve parameterized by \(u\). Just as in Part1, we use the recursive linear interpolation step to evaluate the final, single point \(P_i\) on this specific curve at the parameter \(u\). We repeat this for all \(n\) rows.
    2. Column Evaluation (using parameter \(v\)): After evaluating all the rows, we obtain \(n\) new points: \(P_0, P_1, \dots, P_{n-1}\). These points define a new Bezier curve parameterized by \(v\). We again use the recursive step from Part1 on these points to evaluate the final point \(P\) at the parameter \(v\).

    The point resulting from this final 1D evaluation is the precise point on the Bezier surface at \((u, v)\).

    Implementation Details

    • lerp3D(p0, p1, t): This is the helper function. The function takes two Vector3D points and the double t, and returns the newly interpolated Vector3D point \((1 - t)P_0 + tP_1\).
    • evaluateStep(points, t): This function performs one level of subdivision for a given array of 3D points. It iterates through the points, calls lerp3D for every adjacent pair using parameter t, and returns a new vector containing \(n-1\) points.
    • evaluate1D(points, t): This function fully evaluates a 1D Bezier curve. It repeatedly calls evaluateStep() inside a loop until the vector is reduced to exactly one Vector3D point. It returns this final point, which acts as our \(P_i\) from the algorithm.
    • evaluate(u, v): This is the main function that handles the Bezier surface. For each row, I call evaluate1D(row, u). This evaluates that specific row using the parameter \(u\). I push the resulting point into temp_points. After the loop, temp_points contains the \(n\) evaluated points that form the column. I call evaluate1D(temp_points, v) to evaluate this final curve using the parameter \(v\). This directly returns the final 3D point \(P\) on the surface.

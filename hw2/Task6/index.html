    Part 6: Loop Subdivision for Mesh Upsampling

    Implementation Detail

    I implemented the Loop subdivision algorithm using the recommended process. The core idea is to pre-compute all new vertex positions on the original coarse mesh, perform edge splits and flips, and finally update the vertex positions.

    1. For every original vertex in the mesh, we calculate its new position using the Loop subdivision weighted average formula:

      \[ v_{new} = (1 - n \cdot u) \cdot v_{old} + u \cdot \sum v_{neighbor} \]

      Here, \(n\) is the degree of the vertex. The weighting factor \(u\) is defined as \(u = \frac{3}{16}\) if \(n = 3\), and \(u = \frac{3}{8n}\) for all other cases.

      I iterated through the neighborhood of each vertex using h = h->twin()->next(). During iteration, I accumulated the positions of the neighboring vertices and counted the degree. The result is stored in v->newPosition, and the vertex is flagged with v->isNew = false.

    2. For every original edge, we compute the position of the new vertex that will be inserted at its midpoint. We can identify the two endpoints of the edge (\(A\) and \(B\)) and the opposite vertices in the two adjacent triangles (\(C\) and \(D\)). The formula used is:

      \[ e_{new} = \frac{3}{8}(A + B) + \frac{1}{8}(C + D) \]

      This calculated position is temporarily stored in e->newPosition, and the edge is marked with e->isNew = false.

    3. To prevent the iterator from processing newly created edges, I first collected all original edges into a vector. Then, I iterated through this vector and called splitEdge() on each. The newly returned vertex \(m\) is marked as m->isNew = true, and its position is assigned the pre-computed e->newPosition.

      Finally, I traversed the four edges surrounding \(m\) to flag them: the two edges making up the original edge remain isNew = false, while the two cross edges connecting to the opposite old vertices are marked isNew = true.

    4. I iterated over all edges and flipped any edge that met two conditions: it must be a newly created edge (isNew == true), and it must connect one old vertex and one new vertex.

    5. Lastly, I iterated over all vertices in the new mesh and copied the data from newPosition to the position.

    Sharp Corners and Edges

    Default Behavior

    When Loop subdivision is applied to a cube, the sharp 90-degree corners and straight edges are heavily smoothed out. After several iterations, the cube loses its geometric sharpness entirely.

    In the algorithm, each vertex's new position is calculated as a weighted average of its one-ring neighbors. For vertices at sharp corners, the weighted average forcefully pulls the corner vertex inward, collapsing the sharp feature.

    Preserving Sharpness via Pre-splitting:

    To reduce this smoothing effect and preserve sharp corners, we can manually pre-split the edges surrounding the feature before applying subdivision.

    In the first image, multiple edge splits were performed iteratively on the edges converging at a single front corner of the cube. When the weighted average is calculated, the corner vertex is only pulled toward these close neighbors rather than being pulled toward the distant center of the original faces. As a result, the pre-split corner successfully resists the smoothing effect and remains a sharp point. The rest of the unmodified cube smooths away.

    Cube Asymmetry

    When loading default cube model and performing several iterations of Loop subdivision, the cube becomes slightly asymmetric. This happens because the starting topology of the cube is asymmetric.

    Each square face is constructed using two triangles divided by a single diagonal edge. Loop subdivision updates vertex positions based on their vertex degree. Because these diagonals are oriented in a specific direction, vertices have uneven degrees, so the weighted average pulls the geometry more strongly along the direction of the diagonals.

    Pre-processing Solution:

    To make the cube subdivide symmetrically, we need to make its initial topology symmetric. Before subdividing, I split the diagonal edge on every face of the cube so that each square face is made up of four symmetric triangles.

    With this pre-processing, every corner vertex of the cube has the same degree. When Loop subdivision is applied, the weights are distributed evenly in all directions, causing the cube to smooth into a perfectly symmetric shape.

    Extra Credit: Supporting Meshes with Boundaries

    To support meshes with boundaries, the splits and flips operations remain identical, but the position calculations in Steps 1 and 2 require a different logic.

    Boundary Vertex Update

    For old vertices on a boundary, the standard one-ring neighborhood formula would cause the boundary to shrink aggressively. Instead, we use a cubic B-spline rule. A boundary vertex connects to exactly two other boundary vertices (\(A\) and \(B\)). The new position is calculated as:

    \[ v_{new} = \frac{1}{8}(A + B) + \frac{3}{4} \cdot v_{old} \]

    Boundary Edge Midpoint

    For boundary edges, there are no opposite vertices \(C\) and \(D\) because the edge only borders a single interior triangle. Therefore, the new vertex position simply becomes the exact midpoint of the boundary edge:

    \[ e_{new} = \frac{1}{2}(A + B) \]

    Result

    This ensures that the boundary curves smooth out naturally without collapsing inward.

    Extra Credit: Additional Subdivision Schemes-Modified Butterfly

    The Modified Butterfly scheme is an interpolating scheme, whereas Loop is an approximating scheme. This means that in the Butterfly scheme, the positions of the original vertices are preserved.

    The implementation is identical to Loop subdivision, but Steps 1 and 2 use different calculations.

    Original Vertex

    The Modified Butterfly implementation simply copies the original positions directly: v->newPosition = v->position.

    New Midpoint

    The formula changes depending on the degree of the edge's endpoints:

    • Regular Edges: If both endpoints of an interior edge are regular (\(K = 6\)), we use the standard 8-point butterfly stencil. The new position is calculated using the endpoints \((p, q)\), the opposite vertices in the adjacent triangles \((c_1, c_2)\), and the four wing vertices \((w_1, w_2, w_3, w_4)\) that form the extended neighborhood:
    \[ e_{new} = \frac{1}{2}(p + q) + \frac{1}{8}(c_1 + c_2) - \frac{1}{16}(w_1 + w_2 + w_3 + w_4) \]

    • Extraordinary Vertices: For an extraordinary vertex \(v\) (\(K \neq 6\)), we calculate a weighted sum of its 1-ring neighbors.

      • For \(K=3\): \(s_0 = \frac{5}{12}, \quad s_1 = s_2 = -\frac{1}{12}\)
      • For \(K=4\): \(s_0 = \frac{3}{8}, \quad s_1 = s_3 = 0, \quad s_2 = -\frac{1}{8}\)

      • For \(K \geq 5\), the weights are calculated using trigonometric functions:

        \[ s_j = \frac{1}{K} \left( \frac{1}{4} + \cos\left(\frac{2\pi j}{K}\right) + \frac{1}{2} \cos\left(\frac{4\pi j}{K}\right) \right) \]

      The new vertex position is then: \(\frac{3}{4} v + \sum s_j \cdot neighbor_j\).

    • Boundary Edges: For boundary edges, we use the two endpoints \((p, q)\) and their respective outer boundary neighbors \((a, d)\):

    \[ e_{new} = -\frac{1}{16}a + \frac{9}{16}p + \frac{9}{16}q - \frac{1}{16}d \]

    Result

    Because the Modified Butterfly is an interpolating scheme, the mesh does not shrink inward the way it does with Loop subdivision. Instead, it bulges slightly outward between the original control points to create a smooth surface.
